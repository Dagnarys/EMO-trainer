# EMO Trainer

Простой веб-тренажер для практики набора слов, основанный на изображениях.

## Особенности

- **Практика набора**: Вводите слова, соответствующие показанной картинке.
- **Сохранение прогресса**: Результаты сохраняются в `localStorage`, можно продолжить с места остановки.
- **Анализ результатов**: После завершения отображается таблица с вашими ответами, правильными ответами и статусом.
- **Визуальные подсказки**: Гласные буквы в ответах подсвечиваются красным для лучшего запоминания.
- **Валидация**: Кнопка отправки активна только при вводе текста.
- **Адаптивность**: Интерфейс адаптируется под разные размеры экранов.

## Как запустить

1. Откройте файл `index.html` в любом современном браузере.
2. Введите слово, которое соответствует картинке.
3. Нажмите кнопку подтверждения (галочка) или Enter.
4. После прохождения всех заданий просмотрите результаты на странице результатов.

## Структура проекта

- `index.html` — Главная страница тренажера.
- `result.html` — Страница с результатами.
- `style.css` — Стили приложения.
- `trainer.js` — Логика тренажера (вопросы, навигация, сохранение).
- `assets/` — Иконки интерфейса (галочка, крестик).
- `img/` — Изображения для заданий.
